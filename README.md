Assignments for compiler course DV1655

The aim of this project is to build a compiler for the slimmed-down Java variation MiniJava.

Assignment 1:
1. Lexical analysis (Flex): recognize tokens and report lexical errors.
2. Syntax analysis (Bison): parse minijava programs and construct an Abstract Syntax Tree (AST).

Assignment 2:
1. Construct the symbol table
2. Perform semantic analysis (type checking, scope, etc)
